## 1. Design problem

Keep the outer surface **functional across missions**: low drag intent, no catastrophic growth, **cleanable between missions** with realistic field labour.

**Job card §6:** any textured or mosaic outer surface must stay clean and functional between missions.

**Must-nots:** Deep open osteoderm gaps on first hull · biocidal hero claims without environmental care · soft skins that cannot be cleaned.

---

## 2. Accordance check (physics / biology)

Biofouling is inevitable in productive coastal water. Microstructure that helps drag (riblets) also **traps** organisms. Continuous or near-continuous skins are easier to wipe and inspect than deep mosaics.

**Path A first builds (0–50 m, multi-mission):** prioritize cleanability over biomimetic visual identity.

## 3. Mechanisms (lanes labeled)

### 3.1 Synthetic · foul-release coatings

| | |
|--|--|
| **What** | Low-adhesion surfaces so soft foulants release under shear or gentle wipe |
| **Lane** | Synthetic |
| **Evidence** | High (materials reviews) |
| **Transfer** | Candidate coatings on coupons then hull panels |
| **Do not claim** | Zero fouling forever |

### 3.2 Synthetic · smooth continuous skins

| | |
|--|--|
| **What** | Sealed continuous outer layer over rigid/semi-rigid core |
| **Lane** | Synthetic |
| **Evidence** | High (standard marine practice) |
| **Transfer** | Default first-hull outer strategy |
| **Do not claim** | Boring = bad — boring is durable |

### 3.3 Living lessons · textured skins (only if earned)

| | |
|--|--|
| **What** | Riblets or compliant texture **if** drag/noise gain survives fouling tests |
| **Lane** | Living → Synthetic |
| **Evidence** | Drag high in clean flow; fouling mixed |
| **Transfer** | Only with riblets brief kill tests passed |
| **Do not claim** | Shark skin antifouling as product fact |

### 3.4 Living · leatherback mosaic (explicitly **not** first hull)

| | |
|--|--|
| **What** | Interlocking osteoderm compliance |
| **Lane** | Living |
| **Evidence** | Physiology medium-strong; engineered transfer early |
| **Transfer** | Secondary volume-following only — `briefs/leatherback-osteoderm-volume-following.md` |
| **Do not claim** | Path A v1 outer skin |

## 5. Experiments & kill criteria

| Experiment | Done bar | Kill |
|------------|----------|------|
| Immersion coupons (relevant water) | Growth + wipe-clean time after mission-length soak | Growth or cleaning labour makes multi-mission use impractical |
| Coating durability | Abrasion + UV + salt bench | Coating fails before useful mission count |
| Riblet + coating combo | Drag after fouling cycle | Combo worse than smooth foul-release alone |
