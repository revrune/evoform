## Four bets in plain words

1. **Thrust** — mostly quiet/sparse; continuous prop only when needed  
2. **Riblets** — shark-skin style only if size matches our speed; must stay cleanable  
3. **Hover** — buoyancy + small fins; not a thruster fan forever  
4. **Hydrophone** — put the mic where the vehicle is quietest  

Secondary later: soft fish cosplay, deep “turtle shell” volume-following, ocean field near animals.
