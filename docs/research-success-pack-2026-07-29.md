## 3. Field map (what already exists)

### 3.1 Conventional + glider class
- **Prop AUVs / ROVs:** capable sensors, often **noisy** and energy-heavy for long quiet dwell.  
- **Underwater gliders (VBS):** excellent endurance via buoyancy; slow; not “follow that orca.” Lessons: **sparse thrust**, energy discipline.  
- **Inspection-class mini-AUVs:** hulls, docking, cameras — industrial, not biomimetic co-presence.

### 3.2 Biomimetic / soft robotics (study list)

| Line | What it teaches EvoForm | Limit |
|------|-------------------------|--------|
| **MIT SoFi** (soft robotic fish, Science Robotics era; CSAIL) | Soft body + caudal-like swim; untethered reef swimming; **closer to fish than thruster box**; camera + follow narrative | Endurance ~tens of minutes class historically; depth modest; not mammal co-presence proven |
| **Robotic fish / carangiform lab platforms** (many universities) | Flexible foil, wake control, efficiency claims at certain Re | Often tank-scale; control hard in real sea |
| **Jellyfish / salp pulsed-jet robots** | High efficiency per pulse in some regimes; soft bells | Slow; soft materials + marine durability |
| **Ray / labriform fin robots** | Station-keeping, clutter, quiet local control | Weak open-water transit alone |
| **Artificial muscle / EAP soft actuators** | Future soft actuation | Reliability, power, salt water still hard |

**Takeaway for Path A hybrid (already in brief):**  
Don’t pick one animal. **Compose modes:**  
streamlined sensor body · **variable buoyancy** for sparse depth work · **paired fins** for hover · **pulsed jet or flexible tail** for transit.

### 3.3 CetaVox / CETI-adjacent robotics story
CETI public narrative includes drones, tags, dense listening, **swimming robots** as part of a large funded program.  
**EvoForm does not try to outspend CETI.** EvoForm owns **design-in-accordance-with-nature** clarity and **co-presence ethics** — especially for smaller, quieter, coastal/north-compatible concepts.

## 4. Path A — success criteria (upgrade the showcase brief)

When rewriting `briefs/quiet-small-auv-survey.md`, add an explicit **“hang with”** section:

### 4.1 Acoustic / disturbance budget (non-negotiable)
| Item | Done bar |
|------|----------|
| Propulsor class | Prefer unsteady soft / fin / pulsed over continuous high-RPM open prop for loiter |
| Self-noise target | State a **hypothesis** band (e.g. stay below typical vessel / thruster AUV self-noise at survey speed) — measure later |
| Mission rule | If animal shows avoidance, **abort approach** (ethics over data) |
| Sensor honesty | Hydrophone placement away from thrash; body calm in hover mode |

### 4.2 Loiter / follow
| Item | Done bar |
|------|----------|
| Loiter hours | Target multi-hour (specify battery math with margins) |
| Follow mode | Slow match, not pursuit; max relative speed cap |
| Station-keep | Hold heading/depth in mild current with fins + VBS |
| Burst | Short transit only; then return to quiet mode |

### 4.3 Ethics of approach
| Item | Done bar |
|------|----------|
| Legal | Respect national approach distances / permits (Norway / EU later) |
| Welfare | No tagging requirement for Path A concept; optional passive only |
| Partner | Designed **with** field biologists, not at them |
| Public claim | “Co-presence concept” not “whale friend robot ships next year” |

### 4.4 Physics accordance (keep from existing brief)
- Reynolds / scale honesty  
- No free-lunch efficiency  
- Mode separation: transit ≠ survey ≠ hover  
- Evidence labels: Living · Deep-time · Extreme · Synthetic · Speculative
